# Software-Engineering-Blog-Website
This is my final project for Module 2 name "Software Engineering Blog Website"

💼 AI Full Stack Developer — Personal CV Website

A modern, responsive, multi-page CV and portfolio website built as part of my Module 2 AI Full Stack Developer Course.

The website showcases my professional profile, technical skills, education, and projects. It uses HTML, CSS, and JavaScript to provide an interactive user experience without requiring a backend server.

✨ Features

- Home Page: Personal introduction, profile highlights, and quick-contact form.
- CV & Projects: Organized CV sections, interactive filtering, and downloadable project descriptions.
- Contact Page: Validated contact form with locally saved demo messages.
- Dark/Light Theme: Switch between themes and remember the preference across pages.
- Interactive Modals: Quick-contact popup and saved-message history.
- Form Validation: Checks required fields and validates user input.
- Local Storage: Demonstrates browser-based persistence for theme preferences and demo messages.
- Responsive Design: Layout adapts to desktop, tablet, and mobile screens.
- Accessibility: Semantic HTML, keyboard-friendly controls, and accessible form feedback.

🛠️ Technologies Used

- HTML5 — page structure and semantic markup
- CSS3 — responsive layouts, custom properties, and theme styling
- JavaScript — DOM manipulation, event handling, form validation, and dynamic content
- Browser APIs — localStorage, Blob, and URL object URLs
- Git and GitHub — version control and project hosting
- GitHub Pages — static website deployment

🚀 Getting Started

Option 1: Run Locally

1. Clone the repository:
   
   git clone YOUR_REPOSITORY_URL

2. Open the project folder.

3. Open "index.html" in your browser, or use the Live Server extension in Visual Studio Code.

4. Navigate between Home, CV, and Contact to explore the features.

No package installation or build process is required for the current static version.

Option 2: Deploy with GitHub Pages

1. Push the project files to a GitHub repository.
2. Open the repository's Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select your main branch and the root folder ("/").
6. Save the settings and wait for deployment.
7. Open the published URL provided by GitHub Pages.

🔐 Data and Privacy

This is a frontend demonstration project. Contact form submissions are stored in the browser's local storage and are not sent to a server or database.

Saved messages are specific to the browser and website origin. They are not a secure messaging system and should not contain sensitive information.
